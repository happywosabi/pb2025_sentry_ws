## 1. 层级概述

导航层负责机器人的定位、建图和路径规划，实现自主导航功能。

### 1.1 导航流水线

```mermaid
graph TB
    A[LiDAR点云] --> B[Point-LIO]
    A1[IMU数据] --> B
    B --> C[里程计 /Odometry]

    D[先验点云地图] --> E[GICP重定位]
    C --> E
    E --> F[map→odom TF]

    C --> G[地形分析]
    G --> H[可通行性地图]

    H --> I[Nav2代价地图]
    F --> I
    I --> J[Theta*规划器]
    J --> K[全向PID控制器]
    K --> L[/cmd_vel]

    style B fill:#ffe1e1
    style E fill:#e1ffe1
    style J fill:#e1e1ff
```

## 2. Point-LIO定位节点

### 2.1 节点信息

**包名**: `point_lio`
**节点名**: `pointlio_mapping`
**功能**: LiDAR-惯性里程计，提供高精度实时定位

### 2.2 发布的话题

| 话题名 | 消息类型 | 频率 | 说明 |
|--------|----------|------|------|
| `/Odometry` | nav_msgs/Odometry | 20Hz | 机器人里程计 |
| `/cloud_registered` | sensor_msgs/PointCloud2 | 20Hz | 配准后的点云 |
| `/path` | nav_msgs/Path | 1Hz | 轨迹路径 |

### 2.3 订阅的话题

| 话题名 | 消息类型 | 说明 |
|--------|----------|------|
| `/livox/lidar` | sensor_msgs/PointCloud2 | Livox LiDAR数据 |
| `/livox/imu` | sensor_msgs/Imu | IMU数据 |

### 2.4 关键参数

```yaml
pointlio_mapping:
  common:
    lid_topic: "livox/lidar"
    imu_topic: "livox/imu"

  preprocess:
    lidar_type: 1                   # 1=Livox
    blind: 0.5                      # 盲区距离(m)

  mapping:
    imu_en: true
    filter_size_surf: 0.2           # 表面滤波尺寸
    filter_size_map: 0.2            # 地图滤波尺寸
    lidar_meas_cov: 0.01            # LiDAR测量协方差
```

## 3. 全局重定位节点

### 3.1 节点信息

**包名**: `small_gicp_relocalization`
**节点名**: `small_gicp_relocalization_node`
**功能**: 使用GICP算法进行全局定位

### 3.2 订阅的话题

| 话题名 | 消息类型 | 说明 |
|--------|----------|------|
| `/registered_scan` | sensor_msgs/PointCloud2 | 输入点云 |
| `/initialpose` | geometry_msgs/PoseWithCovarianceStamped | 初始位姿估计 |

### 3.3 发布的TF

- `map` → `odom`：全局定位转换

### 3.4 关键参数

```yaml
small_gicp_relocalization_node:
  num_threads: 4
  global_leaf_size: 0.1             # 全局地图体素大小
  registered_leaf_size: 0.05        # 输入点云体素大小
  max_dist_sq: 3.0                  # 最大对应距离平方
  prior_pcd_file: "/path/to/map.pcd"
```

## 4. 地形分析节点

### 4.1 节点信息

**包名**: `terrain_analysis`
**节点名**: `terrainAnalysis`
**功能**: 评估地形可通行性，生成障碍物地图

### 4.2 发布的话题

| 话题名 | 消息类型 | 说明 |
|--------|----------|------|
| `/terrain_map` | sensor_msgs/PointCloud2 | 可通行性点云 |

### 4.3 关键参数

```yaml
terrainAnalysis:
  scanVoxelSize: 0.05
  vehicleHeight: 0.5
  minRelZ: -1.5
  maxRelZ: 0.5
```

## 5. Nav2导航栈

### 5.1 控制器

**插件**: `pb_omni_pid_pursuit_controller::OmniPidPursuitController`

**功能**: 全向底盘PID追踪控制器

**参数**:
```yaml
controller_server:
  FollowPath:
    plugin: "pb_omni_pid_pursuit_controller::OmniPidPursuitController"
    kp_rho: 1.0
    kp_alpha: 2.0
    kp_beta: -1.0
    max_linear_vel: 2.0
    max_angular_vel: 2.0
```

### 5.2 规划器

**插件**: `nav2_theta_star_planner/ThetaStarPlanner`

**功能**: 任意角度路径规划（无需栅格化）

**参数**:
```yaml
planner_server:
  GridBased:
    plugin: "nav2_theta_star_planner/ThetaStarPlanner"
    how_many_corners: 8
    w_euc_cost: 1.0
    w_traversal_cost: 2.0
```

### 5.3 代价地图配置

**全局代价地图**:
- 尺寸: 30×30m
- 分辨率: 0.05m
- 层级: 静态地图层 + 障碍物层 + 膨胀层

**局部代价地图**:
- 尺寸: 5×5m（滚动窗口）
- 分辨率: 0.05m
- 更新频率: 5Hz
