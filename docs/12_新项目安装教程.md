# pb2025_sentry_ws 项目安装教程

## 概述

本文档提供 pb2025_sentry_ws 工作空间的完整安装指南。该工作空间是 SMBU PolarBear 战队 RoboMaster 2025 哨兵机器人的完整软件系统，包含串口通信、视觉感知、导航定位、决策控制等核心功能。

**预计安装时间**：60-90 分钟（取决于网络速度）

---

## 1. 系统要求

### 1.1 操作系统要求

- **操作系统**：Ubuntu 22.04 LTS（Jammy Jellyfish）
- **架构**：x86_64（amd64）
- **ROS2 发行版**：ROS2 Humble Hawksbill

**重要**：必须使用 Ubuntu 22.04 + ROS2 Humble 组合，不支持其他版本。

### 1.2 硬件配置建议

| 组件 | 最低配置 | 推荐配置 |
|------|---------|---------|
| CPU | Intel i5 8代 / AMD Ryzen 5 | Intel i7 10代+ / AMD Ryzen 7+ |
| 内存 | 8 GB | 16 GB+ |
| 磁盘空间 | 50 GB 可用空间 | 100 GB+ SSD |
| GPU | 集成显卡 | NVIDIA 独立显卡（用于 OpenVINO 加速）|

### 1.3 外设要求

- **串口设备**：USB 转 TTL（波特率 115200）
- **相机**：HikRobot 工业相机（USB 3.0 接口）
- **激光雷达**：Livox MID360（可选，用于导航）
- **IMU**：嵌入式系统集成（通过串口通信）

## 2. 第一步：安装 ROS2 Humble

### 2.1 快速安装（官方源）

```bash
# 设置 locale
sudo apt update && sudo apt install locales
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
export LANG=en_US.UTF-8

# 添加 ROS2 apt 仓库
sudo apt install software-properties-common
sudo add-apt-repository universe
sudo apt update && sudo apt install curl -y
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null

# 安装 ROS2 Humble Desktop（包含 RViz2 和仿真工具）
sudo apt update
sudo apt install ros-humble-desktop -y

# 安装开发工具
sudo apt install ros-dev-tools -y

# 安装 colcon 构建工具
sudo apt install python3-colcon-common-extensions -y
```

### 2.2 验证安装

```bash
source /opt/ros/humble/setup.bash
ros2 --version
# 预期输出：ros2 cli version: 0.18.x
```

### 2.3 设置环境变量（可选但推荐）

```bash
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
source ~/.bashrc
```

**详细安装文档**：https://docs.ros.org/en/humble/Installation.html

## 3. 第二步：安装特殊依赖

### 3.1 OpenVINO 2023.3（必需！）

sp_vision_25 视觉系统依赖 OpenVINO 2023.3 进行神经网络推理。

**重要**：必须使用 2023.3 版本，其他版本不兼容。

#### 方法 1：官方安装脚本（推荐）

```bash
# 下载 OpenVINO 2023.3
cd ~
wget https://storage.openvinotoolkit.org/repositories/openvino/packages/2023.3/linux/l_openvino_toolkit_ubuntu22_2023.3.0.13775.ceeafaf64f3_x86_64.tgz

# 解压
tar -xvzf l_openvino_toolkit_ubuntu22_2023.3.0.13775.ceeafaf64f3_x86_64.tgz

# 移动到标准位置
sudo mv l_openvino_toolkit_ubuntu22_2023.3.0.13775.ceeafaf64f3_x86_64 /opt/intel/openvino_2023.3.0

# 创建符号链接
sudo ln -s /opt/intel/openvino_2023.3.0 /opt/intel/openvino_2023

# 安装依赖
cd /opt/intel/openvino_2023.3.0
sudo -E ./install_dependencies/install_openvino_dependencies.sh

# 设置环境变量
echo "source /opt/intel/openvino_2023/setupvars.sh" >> ~/.bashrc
source ~/.bashrc
```

#### 验证安装

```bash
# 查看可用推理设备
/opt/intel/openvino_2023/samples/cpp/build/hello_query_device

# 预期输出应包含：
# Available devices:
#   Device: CPU
#   Device: GPU（如果有 NVIDIA/Intel GPU）
```

**官方文档**：https://docs.openvino.ai/2023.3/openvino_docs_install_guides_installing_openvino_linux.html

---

### 3.2 small_gicp（必需！）

用于全局定位的点云配准库。

```bash
# 安装依赖
sudo apt install -y libeigen3-dev libomp-dev

# 克隆源码
cd ~
git clone https://github.com/koide3/small_gicp.git
cd small_gicp

# 编译安装
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make -j$(nproc)
sudo make install

# 验证安装
ls /usr/local/include/small_gicp
# 应该看到头文件目录
```

## 5. 第四步：克隆并构建工作空间

### 5.1 克隆项目

```bash
# 创建工作空间
mkdir -p ~/pb2025_sentry_ws
cd ~/pb2025_sentry_ws

# 克隆主仓库（假设使用 Git）
git clone <YOUR_REPO_URL> .

# 或者如果已经在工作空间内
cd ~/pb2025_sentry_ws
```

### 5.2 导入子模块依赖

项目使用 vcstool 管理多个 Git 子仓库。

```bash
cd ~/pb2025_sentry_ws

# 导入所有依赖（从 dependencies.repos）
vcs import --recursive . < dependencies.repos

# 如果遇到网络问题，可以多次执行：
vcs pull ./src
```

**说明**：此步骤会克隆 18 个子模块，包括：
- `hik_camera_ros2_driver`：相机驱动
- `standard_robot_pp_ros2`：串口通信
- `pb2025_rm_vision`：视觉感知模块
- `pb2025_sentry_nav`：导航定位模块
- `pb2025_sentry_behavior`：决策行为树
- 其他依赖（rmoss_core, BehaviorTree.ROS2 等）

### 5.3 安装 ROS2 包依赖

```bash
cd ~/pb2025_sentry_ws

# 初始化 rosdep（仅首次需要）
sudo rosdep init
rosdep update

# 安装所有 ROS2 包依赖
rosdep install -r --from-paths src --ignore-src --rosdistro humble -y
```

### 5.4 编译工作空间

```bash
cd ~/pb2025_sentry_ws

# 完整编译（首次编译，约 5-10 分钟）
colcon build --symlink-install \
  --cmake-args -DCMAKE_BUILD_TYPE=Release \
  --parallel-workers $(nproc)

# source 环境
source install/setup.bash
```

**编译参数说明**：
- `--symlink-install`：符号链接配置文件，修改后无需重新编译
- `-DCMAKE_BUILD_TYPE=Release`：优化编译，提升运行性能
- `--parallel-workers`：并行编译，加速构建

**预期输出**：
```
Summary: 25 packages finished [5min 32s]
```

### 5.5 设置工作空间环境（可选但推荐）

```bash
echo "source ~/pb2025_sentry_ws/install/setup.bash" >> ~/.bashrc
source ~/.bashrc
```

## 6. 第五步：硬件设备配置

### 6.1 串口设备权限配置

```bash
# 添加用户到 dialout 组（允许访问串口）
sudo usermod -a -G dialout $USER

# 创建 udev 规则（固定串口设备名）
sudo tee /etc/udev/rules.d/99-serial.rules > /dev/null <<EOF
# STM32 串口设备
SUBSYSTEM=="tty", ATTRS{idVendor}=="0483", ATTRS{idProduct}=="5740", MODE:="0666", SYMLINK+="ttySTM32"
EOF

# 重新加载 udev 规则
sudo udevadm control --reload-rules
sudo udevadm trigger

# 注销并重新登录以使组权限生效
echo "请注销并重新登录，或执行: newgrp dialout"
```

### 6.2 相机设备权限配置

```bash
# HikRobot 相机需要 USB 权限
sudo tee /etc/udev/rules.d/99-hik-camera.rules > /dev/null <<EOF
# HikRobot USB 相机
SUBSYSTEM=="usb", ATTRS{idVendor}=="2bdf", MODE:="0666"
EOF

# 重新加载 udev 规则
sudo udevadm control --reload-rules
sudo udevadm trigger
```

### 6.3 验证设备连接

```bash
# 检查串口设备
ls -l /dev/ttyACM* /dev/ttySTM32
# 应该看到设备文件，权限为 crw-rw-rw-

# 检查 USB 相机
lsusb | grep -i hik
# 应该看到 HikRobot 设备

# 检查激光雷达（如果使用）
lsusb | grep -i livox
```

## 8. 快速启动指南

### 8.1 系统架构回顾

完整系统包含以下模块：
1. **串口通信**：与 STM32 通信，获取裁判系统数据
2. **视觉感知**：sp_vision_25（新）或 pb2025_rm_vision（旧）
3. **导航定位**：Point-LIO + small_gicp + Nav2
4. **决策控制**：BehaviorTree.CPP 行为树

### 8.2 启动完整系统

```bash
cd ~/pb2025_sentry_ws
source install/setup.bash

# 启动完整系统（使用新视觉 sp_vision_25）
ros2 launch pb2025_sentry_bringup bringup.launch.py \
  world:=<YOUR_WORLD_NAME> \
  use_sp_vision:=True \
  use_rviz:=True \
  params_file:=$(pwd)/src/pb2025_sentry_bringup/params/node_params.yaml
```

**参数说明**：
- `world`：地图名称（如 `arena`，需要对应的 `.yaml`、`.pgm`、`.pcd` 文件）
- `use_sp_vision`：`True` 使用新视觉，`False` 使用旧视觉
- `use_rviz`：是否启动 RViz2 可视化
- `params_file`：参数配置文件路径（必须使用绝对路径）

### 8.3 启动单独模块（调试用）

#### 仅启动串口通信

```bash
ros2 launch standard_robot_pp_ros2 standard_robot_pp_ros2.launch.py \
  use_rviz:=False \
  params_file:=$(pwd)/src/pb2025_sentry_bringup/params/node_params.yaml
```

#### 仅启动新视觉系统

```bash
# 终端 1：启动串口（提供 IMU 数据）
ros2 launch standard_robot_pp_ros2 standard_robot_pp_ros2.launch.py

# 终端 2：启动 sp_vision_25
ros2 launch sp_vision_25 sp_vision_25.launch.py use_sim_time:=False
```

#### 仅启动导航系统

```bash
ros2 launch pb2025_nav_bringup rm_navigation_reality_launch.py \
  world:=<YOUR_WORLD> \
  use_rviz:=True
```

#### 仅启动行为树

```bash
ros2 launch pb2025_sentry_behavior pb2025_sentry_behavior_launch.py
```

### 8.4 验证系统运行

打开新终端，检查话题：

## 9. 常见问题排查

### 9.1 编译错误

#### 问题 1：找不到 OpenVINO

**错误信息**：
```
CMake Error: Could not find OpenVINO
```

**解决方案**：
```bash
# 确认 OpenVINO 已安装
ls /opt/intel/openvino_2023

# 重新 source 环境变量
source /opt/intel/openvino_2023/setupvars.sh

# 将其添加到 .bashrc
echo "source /opt/intel/openvino_2023/setupvars.sh" >> ~/.bashrc
```

#### 问题 2：找不到 small_gicp

**错误信息**：
```
Could not find a package configuration file provided by "small_gicp"
```

**解决方案**：
```bash
# 重新安装 small_gicp（见 3.2 节）
cd ~/small_gicp/build
sudo make install

# 更新 ldconfig
sudo ldconfig
```

#### 问题 3：rosdep 找不到包

**错误信息**：
```
ERROR: the following packages/stacks could not have their rosdep keys resolved
```

**解决方案**：
```bash
# 更新 rosdep 数据库
rosdep update

# 跳过无法解析的包（通常是内部包）
rosdep install -r --from-paths src --ignore-src --rosdistro humble -y
```

---

### 9.2 运行时错误

#### 问题 1：串口打开失败

**错误信息**：
```
[ERROR] Failed to open serial port: /dev/ttyACM0
```

**解决方案**：
```bash
# 检查设备是否存在
ls -l /dev/ttyACM*

# 检查权限
sudo chmod 666 /dev/ttyACM0

# 或添加用户到 dialout 组（见 6.1 节）
sudo usermod -a -G dialout $USER
# 注销并重新登录
```

#### 问题 2：相机无法打开

**错误信息**：
```
[ERROR] Failed to open camera
```

**解决方案**：
```bash
# 检查 USB 连接
lsusb | grep -i hik

# 检查是否有其他程序占用相机
lsof | grep video

# 重启相机（拔插 USB）
```

#### 问题 3：找不到配置文件

**错误信息**：
```
[ERROR] Failed to load config file: configs/sentry.yaml
```

**解决方案**：
```bash
# 确认工作空间已正确 source
source ~/pb2025_sentry_ws/install/setup.bash

# 检查配置文件是否存在
ls ~/pb2025_sentry_ws/install/share/sp_vision_25/configs/sentry.yaml

# 如果不存在，重新编译
cd ~/pb2025_sentry_ws
colcon build --packages-select sp_vision_25 --symlink-install
```

#### 问题 4：找不到地图文件

**错误信息**：
```
[ERROR] Failed to load map: /path/to/your_world.yaml
```

**解决方案**：
```bash
# 确认地图文件存在
ls ~/pb2025_sentry_ws/src/pb2025_sentry_bringup/map/<your_world>.yaml
ls ~/pb2025_sentry_ws/src/pb2025_sentry_bringup/map/<your_world>.pgm
ls ~/pb2025_sentry_ws/src/pb2025_sentry_bringup/pcd/<your_world>.pcd

# 如果缺少地图文件，需要先建图或复制已有地图
```

#### 问题 5：TF 变换失败

**错误信息**：
```
[WARN] Lookup would require extrapolation into the future
```

**解决方案**：
```bash
# 检查 TF 树
ros2 run tf2_tools view_frames

# 查看 TF 关系
ros2 run tf2_ros tf2_echo map base_footprint

# 确认所有 TF 发布节点正常运行
ros2 node list | grep -E "state_publisher|point_lio|gicp"
```

### 9.3 性能问题

#### 问题 1：CPU 占用过高

**解决方案**：
```yaml
# 编辑配置文件：src/pb2025_sentry_bringup/params/node_params.yaml

# 关闭调试可视化
sp_vision_25:
  debug:
    enable_visualization: false
    enable_recorder: false

# 降低相机帧率
hik_camera_ros2_driver:
  acquisition_frame_rate: 120.0  # 从 165 降到 120

# 增加点云滤波
pointlio_mapping:
  mapping:
    filter_size_surf: 0.3  # 从 0.2 增加到 0.3
```

#### 问题 2：延迟过高

**检查方法**：
```bash
# 监控话题延迟
ros2 topic delay /tracker/target

# 检查系统负载
htop

# 检查 DDS 实现
echo $RMW_IMPLEMENTATION
# 应该输出：rmw_cyclonedds_cpp
```

## 附录 B：快速命令参考

```bash
# ========== 编译相关 ==========
cd ~/pb2025_sentry_ws
colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release
colcon build --packages-select sp_vision_25 --symlink-install
source install/setup.bash

# ========== 运行相关 ==========
# 完整系统
ros2 launch pb2025_sentry_bringup bringup.launch.py world:=arena use_sp_vision:=True use_rviz:=True

# 仅串口
ros2 launch standard_robot_pp_ros2 standard_robot_pp_ros2.launch.py

# 仅新视觉
ros2 launch sp_vision_25 sp_vision_25.launch.py

# 仅导航
ros2 launch pb2025_nav_bringup rm_navigation_reality_launch.py world:=arena

# ========== 调试相关 ==========
# 查看话题
ros2 topic list
ros2 topic hz /tracker/target
ros2 topic echo /tracker/target

# 查看节点
ros2 node list
ros2 node info /sp_vision_25

# 查看 TF 树
ros2 run tf2_tools view_frames

# 查看参数
ros2 param list /sp_vision_25
ros2 param get /sp_vision_25 debug.enable_visualization

# ========== 设备检查 ==========
# 串口
ls -l /dev/ttyACM*

# 相机
lsusb | grep -i hik

# 激光雷达
lsusb | grep -i livox
```
