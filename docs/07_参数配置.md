## 1. 中心配置文件

本仓库采用**双配置源**：

| 配置文件 | 适用范围 | 格式 |
|----------|---------|------|
| `src/pb2025_sentry_bringup/params/node_params.yaml` | 串口、导航、决策、旧视觉参数 | ROS2 官方参数格式 |
| `src/sp_vision_25/configs/sentry.yaml` | **sp_vision_25 主感知**（YOLO/EKF/弹道/射击） | sp_vision 独立 YAML |

启动时：

```bash
ros2 launch pb2025_sentry_bringup bringup.launch.py \
  use_sp_vision:=True \
  sp_vision_config:=sentry.yaml \
  params_file:=<绝对路径>/node_params.yaml
```

### 1.1 node_params.yaml 结构

```yaml
# 硬件层
standard_robot_pp_ros2:
  ros__parameters: {...}

hik_camera_ros2_driver:        # 仅 use_sp_vision:=False 时读取
  ros__parameters: {...}

# 旧感知层（已废弃，仅 use_sp_vision:=False 时读取）
armor_detector_opencv:
  ros__parameters: {...}

armor_tracker:
  ros__parameters: {...}

projectile_motion:
  ros__parameters: {...}

# 导航层
pointlio_mapping:
  ros__parameters: {...}

controller_server:
  ros__parameters: {...}

planner_server:
  ros__parameters: {...}

# 决策层
pb2025_sentry_behavior_server:
  ros__parameters: {...}
```

### 1.2 sentry.yaml 结构

见 [§3 感知层参数](#3-感知层参数sp_vision_25-主)。

## 2. 硬件层参数

### 2.1 串口通信

```yaml
standard_robot_pp_ros2:
  ros__parameters:
    device_name: /dev/ttyACM0       # 串口设备
    baud_rate: 115200               # 波特率
    set_detector_color: true        # 自动设置检测颜色
    record_rosbag: true             # 自动录包
    debug: false                    # 调试模式
```

**调试建议**:
- 连接问题 → 检查 `device_name`
- 数据错误 → 启用 `debug: true`

### 2.2 工业相机 *(仅 `use_sp_vision:=False` 旧模式使用)*

> sp_vision_25 模式下相机由 sp_vision 直接设置曝光/增益（见 [§3.1](#3-感知层参数sp_vision_25-主)），本节参数**不生效**。

```yaml
hik_camera_ros2_driver:
  ros__parameters:
    camera_name: "front_industrial_camera"
    pixel_format: "BayerRG8"        # 或 RGB8Packed
    acquisition_frame_rate: 165.0   # 帧率(Hz)
    exposure_time: 5000             # 曝光时间(μs)
    gain: 12.0                      # 增益(dB)
```

**调优建议**:
- 图像过暗 → 增大 `exposure_time` 或 `gain`
- 运动模糊 → 减小 `exposure_time`
- 丢帧 → 降低 `acquisition_frame_rate`

## 3. 感知层参数（sp_vision_25 主）

> 当前主感知由 `sp_vision_25` 承担，使用**独立 YAML** 配置而非 `node_params.yaml` 中的 ROS2 参数。
>
> - 配置文件：`src/sp_vision_25/configs/sentry.yaml`
> - 同名 PCD/地图无关；本节参数与 `world` 无关
> - 切换配置：`sp_vision_config:=<name>.yaml`（默认 `sentry.yaml`）或传绝对路径

### 3.1 sentry.yaml 关键参数

```yaml
# 敌我识别
enemy_color: "red"            # "red" / "blue"

# 检测器
yolo_name: "yolov8"           # yolov5 / yolov8 / yolo11
device: "AUTO"                # CPU / GPU / AUTO
min_confidence: 0.8
use_traditional: true         # 启用传统 CV 兜底

# 相机
exposure_ms: 8                # 曝光时间(毫秒)
gain: 16.9                    # 传感器增益
vid_pid: "2bdf:0001"          # 多相机时按 USB VID:PID 选择

# 跟踪器 / 瞄准
min_detect_count: 5           # 进入 TRACKING 所需连续命中帧
max_temp_lost_count: 25       # TEMP_LOST 容忍帧数
yaw_offset: 0.0               # 度，按机器人手眼标定
pitch_offset: 0.0             # 度
decision_speed: 4.0           # rad/s, 高/低速预测切换阈值
high_speed_delay_time: 0.40   # s, 高速预测提前量
low_speed_delay_time: 0.30    # s, 低速预测提前量
spin_center_track_speed: 6.0  # 反陀螺时打中心的速度阈值
spin_fire_angle: 8.0          # 反陀螺开火窗口(度)

# 自主开火
first_tolerance: 1.5          # 近距离开火角容差(度)
second_tolerance: 0.8         # 远距离开火角容差(度)
auto_fire: true               # sp_vision 自主控制 /cmd_shoot

# 调试
debug:
  enable_visualization: true  # 发布 /sentry_debug/image
  enable_recorder: false      # 写 records/

# 手眼标定（详见 docs/13）
R_camera2gimbal: [[..., ..., ...], ...]  # 3x3 行优先
R_gimbal2imubody: [[..., ..., ...], ...]
camera_matrix: [...]          # fx, 0, cx, 0, fy, cy, 0, 0, 1
distort_coeffs: [...]
```

### 3.2 调参场景速查

| 现象 | 调整参数 | 方向 |
|------|----------|------|
| pitch/yaw 系统性偏移 | `pitch_offset` / `yaw_offset` | 标定补偿（度） |
| 跟踪频繁抖动/跳目标 | `min_detect_count` | ↑（更稳） |
| 跟踪太慢响应 | `min_detect_count` | ↓ |
| 短暂遮挡掉目标 | `max_temp_lost_count` | ↑ |
| 高速运动打不中 | `high_speed_delay_time` | ↑ |
| 低速运动超调 | `low_speed_delay_time` | ↓ |
| 误检装甲板 | `min_confidence` | ↑ 0.85+ |
| 漏检装甲板 | `min_confidence` | ↓ 0.7 |
| 图像过暗 | `exposure_ms` / `gain` | ↑ |
| 图像过曝 | `exposure_ms` / `gain` | ↓ |
| 不敢开火 | `first_tolerance` / `second_tolerance` | ↑ |
| 频繁误射 | `first_tolerance` / `second_tolerance` | ↓ |

> 完整参数语义、坐标系约定与手眼标定流程见 [`docs/09_sp_vision_25分析.md`](./09_sp_vision_25分析.md) 与 [`docs/13_四元数转换与参数调优.md`](./13_四元数转换与参数调优.md)。

## 附录 3'. 旧 pb2025_rm_vision 参数（仅 `use_sp_vision:=False` 时使用，已废弃）

> ⚠️ 以下参数仅在启用旧视觉链路时被读取；新部署不应再依赖。

### 3'.1 装甲板检测 (OpenCV)

```yaml
armor_detector_opencv:
  ros__parameters:
    detect_color: 0                 # 0=红, 1=蓝
    binary_thres: 80                # 二值化阈值(0-255)

    # 灯条筛选
    light.min_ratio: 0.1
    light.max_ratio: 1.0
    light.max_angle: 45.0

    # 装甲板筛选
    armor.min_light_ratio: 0.8
    armor.min_small_center_distance: 0.8
    armor.max_small_center_distance: 3.2

    # 分类器
    classifier_threshold: 0.25
```

| 场景 | 参数 | 调整 |
|------|------|------|
| 强光环境 | `binary_thres` | 100-120 |
| 弱光环境 | `binary_thres` | 60-80 |
| 误检灯条多 | `light.min_ratio` | 0.15-0.2 |
| 漏检装甲板 | `armor.min_light_ratio` | 0.7 |
| 数字识别错误 | `classifier_threshold` | 0.4-0.6 |

### 3'.2 目标追踪

```yaml
armor_tracker:
  ros__parameters:

    ekf.sigma2_q_r: 80.0

    tracker.max_match_distance: 0.5
```

### 3'.3 弹道计算


## 4. 导航层参数

### 4.1 Point-LIO

```yaml
pointlio_mapping:
  ros__parameters:
    mapping:
      filter_size_surf: 0.2         # 表面滤波
      filter_size_map: 0.2          # 地图滤波
      lidar_meas_cov: 0.01          # LiDAR协方差
```

### 4.2 Nav2控制器

```yaml
controller_server:
  ros__parameters:
    FollowPath:
      plugin: "pb_omni_pid_pursuit_controller::OmniPidPursuitController"
      kp_rho: 1.0                   # 距离增益
      kp_alpha: 2.0                 # 方向增益
      kp_beta: -1.0                 # 朝向增益
      max_linear_vel: 2.0           # 最大线速度(m/s)
      max_angular_vel: 2.0          # 最大角速度(rad/s)
```

**调优**:
- 震荡 → 降低 `kp_alpha`
- 响应慢 → 增大 `kp_rho`

### 4.3 Nav2规划器

```yaml
planner_server:
  ros__parameters:
    GridBased:
      plugin: "nav2_theta_star_planner/ThetaStarPlanner"
      w_euc_cost: 1.0               # 欧氏距离权重
      w_traversal_cost: 2.0         # 可通行性权重
```

### 4.4 代价地图

```yaml
global_costmap:
  global_costmap:
    ros__parameters:
      width: 30
      height: 30
      resolution: 0.05
      robot_radius: 0.25            # 机器人半径(m)
      inflation_radius: 0.3         # 膨胀半径(m)
      cost_scaling_factor: 3.0      # 代价缩放
```

**调优**:
- 过不去窄道 → 减小 `robot_radius`
- 撞障碍物 → 增大 `inflation_radius`

## 5. 决策层参数

### 5.1 行为树

```yaml
pb2025_sentry_behavior_server:
  ros__parameters:
    tick_frequency: 5               # Tick频率(Hz)
    groot2_port: 1667               # Groot2端口
    plugins:
      - /path/to/bt_plugins.so
    behavior_trees:
      - /path/to/sentry_behavior.xml
```

### 5.2 行为树节点参数

```yaml
# CalculateAttackPose节点
```

## 6. 调试参数建议

### 6.1 单模块调试

**视觉调试 (sp_vision_25 主)**:
```yaml
# src/sp_vision_25/configs/sentry.yaml
debug:
  enable_visualization: true   # 发布 /sentry_debug/image
  enable_recorder: false       # 写入 records/
```
查看：`ros2 run rqt_image_view rqt_image_view /sentry_debug/image`

**视觉调试 (旧模式)**:
```yaml
armor_detector_opencv.debug: true
armor_tracker.debug: true
```

**导航调试**:
```yaml
controller_server.FollowPath.debug: true
```

### 6.2 性能优化

**降低CPU占用**:
```yaml
# 降低相机帧率
hik_camera_ros2_driver.acquisition_frame_rate: 120.0

# 降低点云分辨率
pointlio_mapping.mapping.filter_size_surf: 0.3

# 降低行为树频率
pb2025_sentry_behavior_server.tick_frequency: 3
```

### 6.3 参数热更新

某些参数支持运行时修改：

```bash
# 使用rqt_reconfigure
ros2 run rqt_reconfigure rqt_reconfigure

# 命令行修改
ros2 param set /armor_detector_opencv binary_thres 100
ros2 param get /armor_detector_opencv binary_thres
```

## 7. 参数备份与恢复

### 7.1 导出参数

```bash
# 导出所有参数
ros2 param dump /armor_detector_opencv > opencv_params_backup.yaml

# 导出所有节点参数
ros2 param dump --print
```

### 7.2 参数版本管理

建议为不同场景维护参数文件：

```
params/
├── node_params.yaml              # 默认参数
├── competition_params.yaml       # 比赛参数
├── debug_params.yaml             # 调试参数
└── simulation_params.yaml        # 仿真参数
```

使用时指定：
```bash
ros2 launch pb2025_sentry_bringup bringup.launch.py \
  params_file:=$(pwd)/src/pb2025_sentry_bringup/params/competition_params.yaml
```
