## 1. 中心配置文件

### 1.1 文件位置

**主配置文件**: `src/pb2025_sentry_bringup/params/node_params.yaml`

所有节点参数统一配置在此文件中，通过 `params_file` 参数传递给启动文件。

### 1.2 文件结构

```yaml
# 硬件层
standard_robot_pp_ros2:
  ros__parameters: {...}

hik_camera_ros2_driver:
  ros__parameters: {...}

# 感知层
armor_detector_opencv:
  ros__parameters: {...}

armor_tracker:
  ros__parameters: {...}

projectile_motion:
  ros__parameters: {...}

# 导航层
pointlio_mapping:
  ros__parameters: {...}

controller_server:
  ros__parameters: {...}

planner_server:
  ros__parameters: {...}

# 决策层
pb2025_sentry_behavior_server:
  ros__parameters: {...}
```

## 2. 硬件层参数

### 2.1 串口通信

```yaml
standard_robot_pp_ros2:
  ros__parameters:
    device_name: /dev/ttyACM0       # 串口设备
    baud_rate: 115200               # 波特率
    set_detector_color: true        # 自动设置检测颜色
    record_rosbag: true             # 自动录包
    debug: false                    # 调试模式
```

**调试建议**:
- 连接问题 → 检查 `device_name`
- 数据错误 → 启用 `debug: true`

### 2.2 工业相机

```yaml
hik_camera_ros2_driver:
  ros__parameters:
    camera_name: "front_industrial_camera"
    pixel_format: "BayerRG8"        # 或 RGB8Packed
    acquisition_frame_rate: 165.0   # 帧率(Hz)
    exposure_time: 5000             # 曝光时间(μs)
    gain: 12.0                      # 增益(dB)
```

**调优建议**:
- 图像过暗 → 增大 `exposure_time` 或 `gain`
- 运动模糊 → 减小 `exposure_time`
- 丢帧 → 降低 `acquisition_frame_rate`

## 3. 感知层参数

### 3.1 装甲板检测 (OpenCV)

```yaml
armor_detector_opencv:
  ros__parameters:
    detect_color: 0                 # 0=红, 1=蓝
    binary_thres: 80                # 二值化阈值(0-255)
    
    # 灯条筛选
    light.min_ratio: 0.1            # 最小长宽比
    light.max_ratio: 1.0            # 最大长宽比
    light.max_angle: 45.0           # 最大倾斜角度
    
    # 装甲板筛选
    armor.min_light_ratio: 0.8      # 灯条长度比阈值
    armor.min_small_center_distance: 0.8
    armor.max_small_center_distance: 3.2
    
    # 分类器
    classifier_threshold: 0.25      # 置信度阈值
```

**常见场景调优**:

| 场景 | 参数 | 调整 |
|------|------|------|
| 强光环境 | `binary_thres` | 100-120 |
| 弱光环境 | `binary_thres` | 60-80 |
| 误检灯条多 | `light.min_ratio` | 0.15-0.2 |
| 漏检装甲板 | `armor.min_light_ratio` | 0.7 |
| 数字识别错误 | `classifier_threshold` | 0.4-0.6 |

### 3.2 目标追踪

```yaml
armor_tracker:
  ros__parameters:
    target_frame: "gimbal_pitch_odom"
    max_armor_distance: 10.0        # 最大追踪距离(m)
    
    # EKF过程噪声
    ekf.sigma2_q_xyz: 0.05          # 位置噪声
    ekf.sigma2_q_yaw: 5.0           # 偏航角噪声
    ekf.sigma2_q_r: 80.0            # 半径噪声
    
    # EKF测量噪声
    ekf.r_xyz_factor: 0.0004
    ekf.r_yaw: 0.003
    
    # 追踪器
    tracker.max_match_distance: 0.5 # 最大匹配距离(m)
    tracker.tracking_thres: 5       # 追踪阈值(帧数)
    tracker.lost_time_thres: 1.0    # 丢失阈值(s)
```

**调优建议**:

| 问题 | 参数 | 方向 |
|------|------|------|
| 追踪抖动 | `sigma2_q_xyz` | ↓ (减小, 信任测量) |
| 预测不准 | `sigma2_q_xyz` | ↑ (增大, 信任模型) |
| 频繁丢失 | `lost_time_thres` | ↑ |
| 误匹配 | `max_match_distance` | ↓ |

### 3.3 弹道计算

```yaml
projectile_motion:
  ros__parameters:
    projectile:
      offset_pitch: 0.0             # pitch补偿(rad)
      offset_yaw: 0.0               # yaw补偿(rad)
      offset_time: 0.1              # 时间补偿(s)
      initial_speed: 21.5           # 弹丸初速(m/s)
      solver_type: "gravity"        # 或 "gaf"
```

**校准流程**:
1. 测试固定距离射击（5m、7m、10m）
2. 记录实际偏差
3. 调整 `offset_pitch` 和 `offset_yaw`
4. 动态目标调整 `offset_time`

## 4. 导航层参数

### 4.1 Point-LIO

```yaml
pointlio_mapping:
  ros__parameters:
    mapping:
      filter_size_surf: 0.2         # 表面滤波
      filter_size_map: 0.2          # 地图滤波
      lidar_meas_cov: 0.01          # LiDAR协方差
```

### 4.2 Nav2控制器

```yaml
controller_server:
  ros__parameters:
    FollowPath:
      plugin: "pb_omni_pid_pursuit_controller::OmniPidPursuitController"
      kp_rho: 1.0                   # 距离增益
      kp_alpha: 2.0                 # 方向增益
      kp_beta: -1.0                 # 朝向增益
      max_linear_vel: 2.0           # 最大线速度(m/s)
      max_angular_vel: 2.0          # 最大角速度(rad/s)
```

**调优**:
- 震荡 → 降低 `kp_alpha`
- 响应慢 → 增大 `kp_rho`

### 4.3 Nav2规划器

```yaml
planner_server:
  ros__parameters:
    GridBased:
      plugin: "nav2_theta_star_planner/ThetaStarPlanner"
      w_euc_cost: 1.0               # 欧氏距离权重
      w_traversal_cost: 2.0         # 可通行性权重
```

### 4.4 代价地图

```yaml
global_costmap:
  global_costmap:
    ros__parameters:
      width: 30
      height: 30
      resolution: 0.05
      robot_radius: 0.25            # 机器人半径(m)
      inflation_radius: 0.3         # 膨胀半径(m)
      cost_scaling_factor: 3.0      # 代价缩放
```

**调优**:
- 过不去窄道 → 减小 `robot_radius`
- 撞障碍物 → 增大 `inflation_radius`

## 5. 决策层参数

### 5.1 行为树

```yaml
pb2025_sentry_behavior_server:
  ros__parameters:
    tick_frequency: 5               # Tick频率(Hz)
    groot2_port: 1667               # Groot2端口
    plugins:
      - /path/to/bt_plugins.so
    behavior_trees:
      - /path/to/sentry_behavior.xml
```

### 5.2 行为树节点参数

```yaml
# CalculateAttackPose节点
CalculateAttackPose:
  attack_radius: 3.0                # 攻击半径(m)
  num_sectors: 36                   # 扇区数
  cost_threshold: 50                # 代价阈值
  visualize: true                   # 可视化
```

## 6. 调试参数建议

### 6.1 单模块调试

**视觉调试**:
```yaml
armor_detector_opencv.debug: true
armor_tracker.debug: true
```

**导航调试**:
```yaml
controller_server.FollowPath.debug: true
```

### 6.2 性能优化

**降低CPU占用**:
```yaml
# 降低相机帧率
hik_camera_ros2_driver.acquisition_frame_rate: 120.0

# 降低点云分辨率
pointlio_mapping.mapping.filter_size_surf: 0.3

# 降低行为树频率
pb2025_sentry_behavior_server.tick_frequency: 3
```

### 6.3 参数热更新

某些参数支持运行时修改：

```bash
# 使用rqt_reconfigure
ros2 run rqt_reconfigure rqt_reconfigure

# 命令行修改
ros2 param set /armor_detector_opencv binary_thres 100
ros2 param get /armor_detector_opencv binary_thres
```

## 7. 参数备份与恢复

### 7.1 导出参数

```bash
# 导出所有参数
ros2 param dump /armor_detector_opencv > opencv_params_backup.yaml

# 导出所有节点参数
ros2 param dump --print
```

### 7.2 参数版本管理

建议为不同场景维护参数文件：

```
params/
├── node_params.yaml              # 默认参数
├── competition_params.yaml       # 比赛参数
├── debug_params.yaml             # 调试参数
└── simulation_params.yaml        # 仿真参数
```

使用时指定：
```bash
ros2 launch pb2025_sentry_bringup bringup.launch.py \
  params_file:=$(pwd)/src/pb2025_sentry_bringup/params/competition_params.yaml
```
