================================================================================
关键参数调整
================================================================================

位于：src/pb2025_sentry_bringup/params/node_params.yaml

【检测参数】
armor_detector_opencv.detect_color: 0  # 0=红色, 1=蓝色
armor_detector_opencv.binary_thres: 80  # 二值化阈值（60-120）
armor_detector_opencv.classifier_threshold: 0.25  # 置信度阈值（0.2-0.6）

【跟踪参数】
armor_tracker.ekf.sigma2_q_xyz: 0.05  # 位置过程噪声（越小越信任测量）
armor_tracker.tracker.tracking_thres: 5  # 开始跟踪的帧数
armor_tracker.tracker.lost_time_thres: 1.0  # 丢失目标的时间阈值（秒）

【弹道参数】
projectile_motion.projectile.offset_pitch: 0.0  # Pitch 偏移（需标定）
projectile_motion.projectile.offset_yaw: 0.0  # Yaw 偏移（需标定）
projectile_motion.projectile.offset_time: 0.1  # 预测时间（秒）
projectile_motion.projectile.initial_speed: 21.5  # 弹丸初速（m/s）

【射击逻辑】
projectile_motion 节点自动处理射击：
- 未跟踪目标时：/cmd_shoot = 0（停止射击）
- 正在跟踪目标时：/cmd_shoot = 1（连续射击）

================================================================================
常见问题排查
================================================================================

问题1：检测不到装甲板
检查：
- 确认 detect_color 设置正确（0=红色, 1=蓝色）
- 调整 binary_thres（光线亮增大，光线暗减小）
- 降低 classifier_threshold 到 0.2
- 在 RViz 中查看 /detector/binary_img 调试图像

问题2：跟踪频繁丢失
检查：
- 增大 lost_time_thres 到 1.5 秒
- 减小 ekf.sigma2_q_xyz 到 0.03（更信任测量）
- 增大 tracker.max_match_distance

问题3：云台不响应
检查：
- 串口连接：ls -l /dev/ttyACM*
- 串口权限：sudo usermod -a -G dialout $USER
- 话题发布：ros2 topic hz /cmd_gimbal
- STM32 固件是否正常

问题4：射击不工作
检查：
- /cmd_shoot 话题是否发布：ros2 topic echo /cmd_shoot
- 确认正在跟踪目标：ros2 topic echo /tracker/target
- 检查弹药量（如果使用裁判系统）

问题5：Gazebo 仿真启动失败
检查：
- Ignition Fortress 是否安装
- 环境变量：echo $IGN_GAZEBO_RESOURCE_PATH
- 重新编译：colcon build --packages-select rmu_gazebo_simulator

1. 启动视觉系统（方案1或方案2）

【第四步】：验证射击逻辑
1. 查看 /cmd_shoot 命令
2. 确认跟踪时自动射击
3. 调整 initial_speed 匹配实际弹速

【第五步】：完整系统测试
