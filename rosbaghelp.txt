================================================================================
注意事项
================================================================================

1. 机器人静止说明：
   - 方案A/B：只启动传感器节点，机器人完全静止（底盘+云台）
   - 方案C：启动完整系统，底盘静止，云台可能移动

2. 文件大小优化：
   - 使用 image/compressed 代替原始图像（减少10倍）
   - 使用 zstd 压缩（额外减少30%）
   - 方案A/B: 3分钟约7GB，方案C: 3分钟约8.5GB

3. QoS 匹配：
   - qos_overrides.yaml 已配置传感器话题的 best_effort QoS
   - 录制时自动匹配发布者的 QoS 策略

4. 播放调试技巧：
   - 使用 --clock 提供仿真时钟
   - 使用 --rate 2.0 加速播放
   - 设置 use_sim_time:=True 让节点使用bag时钟
   - 设置 armor_tracker.target_frame:=base_footprint 解决TF问题

5. 降频录制（如需严格30Hz图像）：
   # 先启动降频节点
   ros2 run topic_tools throttle messages \
     /front_industrial_camera/image/compressed 30.0 \
     /front_industrial_camera/image/compressed/throttled &

   # 然后录制降频话题（替换原图像话题）
